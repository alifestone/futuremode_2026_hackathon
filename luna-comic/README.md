# LUNA — LIVE AI Comic

An editable comic project for CSFCCA's virtual idol **LUNA**, derived from
`LUNA_MV_製作計畫書.docx` and the existing character sheet.

Claude Code owns the files and automation; LlamaGen's Comic MCP does the visual
generation and refinement.

## Layout

```
luna-comic/
├── project.json              # character bible, style lock, generation settings
├── storyboard/
│   ├── beatmap.json          # measured tempo/sections/hard cuts (do not hand-edit)
│   ├── shots.json            # THE EDITABLE SOURCE — 24 shots, 16:9, video
│   └── STORYBOARD.md         # human-readable shot table
├── lyrics/                   # generated by align_lyrics.py
│   ├── lyrics.json           # 23 lines on the bar grid
│   └── lyrics.srt            # same timings as subtitles, for the edit
├── panels/panels.json        # superseded — 13 panels, 3:4, comic stills
├── assets/reference/         # LUNA character sheet (consistency anchor)
├── scripts/
│   ├── connect_mcp.sh        # one-time MCP registration
│   ├── analyze_audio.py      # 歌曲.mp3 -> beatmap numbers (re-run only on re-export)
│   ├── align_lyrics.py       # 歌詞.txt + beatmap.json -> lyrics/ + shots' lyric_lines
│   ├── build_shots.py        # shots.json -> out/shot_prompts.{json,md}   ← video
│   └── build_prompts.py      # panels.json -> out/prompts.json            ← legacy
└── out/                      # compiled prompts + change hashes (generated)
```

**Two tracks, two compilers.** `shots.json` (24 shots, 16:9) is authoritative and
compiles with `build_shots.py`. `panels.json` (13 panels, 3:4) is the earlier comic
track, kept but superseded — its timeline predates the audio measurement. The two
carry different aspect ratios and different negative prompts, which is why they have
separate compilers rather than one shared script.

## Setup

1. Get an API token from LlamaGen → Settings → API.
2. Export it, then register the MCP:

   ```bash
   export LLAMAGEN_API_TOKEN='your-token'
   bash scripts/connect_mcp.sh
   ```

   PowerShell equivalent — keep it on **one line**:

   ```powershell
   $env:LLAMAGEN_API_TOKEN = "your-token"
   claude mcp add --scope user --transport http llamagen https://llamagen.ai/api/mcp --header "Authorization: Bearer $env:LLAMAGEN_API_TOKEN"
   ```

   > `--header` is variadic (`--header <header...>`), so it consumes everything
   > after it. The name and URL must come **before** `--header`, or the CLI
   > fails with `error: missing required argument 'name'`.

3. Restart Claude Code, confirm with `/mcp` or `claude mcp get llamagen`.

## The edit loop

The point of this structure: **shots.json is the only file you edit by hand.**
(`lyric_lines` is the exception — it is generated, so leave it alone.)

1. Edit a shot's `action`, `expression`, `camera`, or `caption`.
2. `python scripts/build_shots.py` — reports exactly which shots changed.
3. Regenerate only those shots. `--model "ComfyUI MiniMax H3"` prints the local
   provider's batch,
   which is the unit you actually paste into a single interface.

Because every shot carries the same `character_ref` and the same `locked_keywords`
from `project.json`, regenerating one shot does not drift the others — the
consistency problem the plan doc calls out as the project's main risk. Never drop
either field from a shot.

The same loop applies to the legacy comic track with `build_prompts.py` /
`panels.json`.

## Lyrics

`歌詞.txt` is one unbroken paragraph with no timecodes. `align_lyrics.py` splits it
into 23 singable lines, maps them onto the 12 measured sections, and writes
`lyrics/lyrics.json` + `lyrics.srt`, then fills each shot's `lyric_lines`.

> **These timings are estimated, not measured.** There is no vocal-onset detection
> or forced alignment here — unlike `beatmap.json`, which is measured from the audio.
> Section assignment is by hand and placement within a section is proportional to
> line length. Only the three lines marked `anchor: hard_cut` (0:45.77, 1:33.32,
> 2:12.90) are exact. Treat the rest as a starting point to nudge in the edit.

Captions and lyric subtitles are different things: `caption` is a designed visual
title card, lyric subtitles come from the SRT. Where both land on one shot (S05),
the caption wins.

## Generation rules

Per LlamaGen's integration guide, before any generation:

- Call `get_comic_api_usage` first.
- **Stop if remaining credits < 5,000.**
- Get explicit approval before starting a batch — LlamaGen credits are separate
  from Claude Code usage costs.

Available MCP tools: `search_llamagen_docs`, `get_comic_api_usage`,
`create_comic_generation`, `get_comic_generation_status`.
